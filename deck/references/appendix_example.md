## 4. 구성요소 · 최적화
- **활성화 함수** (11:01~14:55): 비선형성을 부여해 깊은 표현을 가능케 함.
  - 시그모이드 `σ(x)=1/(1+exp(−x))` · 소프트맥스(다중분류 출력) · Tanh · ReLU(`max(0,x)`).
- **역전파** (11:30): 연쇄법칙으로 기울기를 거꾸로 전파해 가중치 갱신.
- **경사하강 / SGD** (1:37/1:58): 손실 최소점 탐색. SGD는 표본 단위 갱신.
- **학습률** (16:05): 단계 크기. 크면 발산, 작으면 느림.
- **드롭아웃** (14:07) / **정규화·L1·L2** (2:36/15:53): 과적합 억제.
- **손실/비용 함수** (13:18/16:44): 예측–정답 차이를 정량화 → 최소화 대상.

## 5. 평가 · 검증
- **혼동행렬** (17:00): TP/FP/FN/TN. 정밀도·재현율의 출발점.
- **정밀도** `TP/(TP+FP)` (17:22) · **재현율** `TP/(TP+FN)` (17:28) — 보통 트레이드오프, **F1**은 둘의 조화평균.

## 7. 핵심 수식 (복사용)
```
경사 하강법   θ ← θ − η · ∇J(θ)
MSE          MSE = (1/n) · Σ (yᵢ − ŷᵢ)²
시그모이드     σ(x) = 1 / (1 + exp(−x))
소프트맥스     softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
베이즈 정리     P(A|B) = P(B|A) · P(A) / P(B)
```

## 8. 영상 자막(ASR) 정정
영상 자동자막의 오인식을 바로잡았다: **Base theorem → Bayes 정리**, **Bugging → Bagging**,
**Humming → Hamming**, **Jakart → Jaccard**, **LSDM → LSTM**, **Ukidian → Euclidean**,
**"during complete" → Turing complete**.
